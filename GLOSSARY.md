# Galaxy Theme

Personal visual customization project for unrooted stock Samsung Galaxy (One UI) devices, covering concept design, asset preparation, and on-device application.

## Language

**Theme**:
A complete personal visual customization unit for unrooted stock One UI, encompassing wallpaper, icon pack, system UI colors (Quick Panel, Settings, Dialer, etc.), and Lock Screen / AOD styling.
_Avoid_: Skin, UI pack, Preset
